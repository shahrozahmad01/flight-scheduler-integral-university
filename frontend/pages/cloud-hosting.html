Cloud Hosting Guide

This page explains how to deploy the Aircraft Network Flight Scheduler to a cloud provider and keep the frontend and backend running together.

Deployment Overview

  • The backend is a Flask API in backend/app.py.
  • The frontend is a static site in frontend/.
  • The Flask app is configured to serve the static frontend files from the same app.

Recommended Cloud Hosts

  1. Azure App Service (recommended for Python apps)
  2. Render or similar host that supports Python

Azure App Service Steps

  1. Push the repo to GitHub.
  2. Create a new Linux Web App with Python 3.14.
  3. Set the build command to cd backend && pip install -r requirements.txt.
  4. Set the start command to cd backend && python app.py.
  5. Open the deployed URL and navigate to /index.html.

Render / Other Hosts

  1. Select the repo branch.
  2. Use cd backend && pip install -r requirements.txt as build command.
  3. Use cd backend && python app.py as start command.
  4. Visit /index.html on the deployed domain.

Important Notes

  • The backend now supports serving the frontend static files from frontend/.
  • The app uses requirements.txt for dependency installation.
  • If using Azure, make sure Startup Command points at backend/app.py.
